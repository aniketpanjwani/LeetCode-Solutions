# Starter Sequence

Use this fixed starter sequence for the first seven study units. It removes day-one choice and builds the habit before switching fully to [session-protocol.md](session-protocol.md).

These are not days and they are not a quota. You can do one unit in a sitting or several. After each unit, update [review-log.md](review-log.md) so the next restart knows exactly where to pick up.

| Unit | Type | Pattern / problem | Why now |
| --- | --- | --- | --- |
| 1 | LEARN | Stack simulation: LC2390 Removing Stars From a String | Easiest anchor; builds confidence with a clean stack invariant. |
| 2 | LEARN | Greedy/math: LC1753 Maximum Score From Removing Stones | Small formula problem; practice deriving limits before coding. |
| 3 | RE-DRILL | LC2390 Removing Stars From a String | First speed pass from memory. |
| 4 | LEARN | Prefix/suffix parity: LC1664 Ways to Make a Fair Array | Introduces one-pass state updates and deletion parity shifts. |
| 5 | REVIEW | Logged rows in review-log.md | Seed the review habit even if the log is still thin. |
| 6 | LEARN | Bounded Hamming distance: LC2452 Words Within Two Edits of Dictionary | Practice a simple correct brute force before thinking about optimization. |
| 7 | RE-DRILL / catch-up | Re-solve a shaky one or finish any carryover | Let the log and carryover rule decide the target. |

Defer the two hardest anchors until after this starter sequence:

- LC1927 Sum Game: game-theory compression can be conceptually slippery.
- LC1671 Minimum Number of Removals to Make Mountain Array: Hard, LIS from both sides.

After these starter units, stop using this file as a schedule. Open [session-protocol.md](session-protocol.md) for the ongoing selector. This file deliberately does not restate the rotation rule, so the protocol remains the single source of truth.
